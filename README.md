# TransitCredee
TransitCred ($TCRD) is a Solana utility token rewarding eco-friendly commuting to cut urban traffic. Featuring a 1B fixed supply with deflationary burns, users stake tokens in a custom Rust/Anchor veTCRD vault for governance and real-world transit pass yields. Fair-launching on Pump.fun to Raydium, it unites clean mobility with community rewards.
